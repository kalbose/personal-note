# Персональный блокнот на api

Сервис индивидуальных заметок на Go (≥1.24).

## Структура проекта
- `model` — структуры данных (независимый пакет)
- `database` — работа с SQLite
- `application` — бизнес-логика, авторизация
- `transport` — HTTP-хэндлеры
- `main` — точка входа

## Запуск
```bash
go mod tidy
go run main/main.go
